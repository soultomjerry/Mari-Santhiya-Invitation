MARI MAGESH & SANTHIYA — INTERACTIVE WEDDING INVITATION

Files:
- index.html — complete single-page invitation. CSS and JavaScript are embedded.

How to use:
1. Extract the ZIP.
2. Open index.html in Chrome/Edge/Safari.
3. For best mobile testing, host the folder on any static web host (GitHub Pages, Netlify, Vercel, etc.).

Included interactions:
- Swipe/drag or click to open the animated temple-style cover doors
- Scroll-triggered reveal animations
- Scratch-to-reveal date and muhurtham time
- Google Maps links for wedding and reception
- WhatsApp RSVP button
- Google Calendar button
- Native Share button / copy fallback
- Floating music toggle using lightweight Web Audio
- Responsive mobile and desktop layout

Notes:
- Google Fonts are loaded from fonts.googleapis.com when online; the page still renders with fallback fonts offline.
- The map links are the exact links supplied for the two venues.
- Replace/add images later if you want couple photos or custom deity artwork.
